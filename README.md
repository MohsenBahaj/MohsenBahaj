## 📦 Open Source

[![flutter_ios_capabilities_setup](https://img.shields.io/pub/v/flutter_ios_capabilities_setup.svg?label=flutter_ios_capabilities_setup&color=00ADB5)](https://pub.dev/packages/flutter_ios_capabilities_setup)
![pub points](https://img.shields.io/pub/points/flutter_ios_capabilities_setup?color=00ADB5)

**[flutter_ios_capabilities_setup](https://github.com/MohsenBahaj/flutter_ios_capabilities_setup)** is a CLI tool that configures iOS capabilities for Flutter **without opening Xcode**. It works from Windows, macOS, and Linux and fits CI/CD on Codemagic and GitHub Actions.

- Firebase and Push Notifications, Background Modes, and Google Maps setup
- Updates `project.pbxproj`, `Info.plist`, `AppDelegate.swift`, and creates `Runner.entitlements`
- Detects a `GoogleService-Info.plist` Bundle ID mismatch before it causes a silent crash
- Safe to run multiple times, tested on Xcode 26.1

```bash
dart pub global activate flutter_ios_capabilities_setup
flutter_ios_capabilities_setup
```
